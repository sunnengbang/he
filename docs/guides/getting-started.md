# 在 GitHub 中维护知识库

- 更新日期：2026-10-11
- 标签：GitHub、Markdown、知识管理
- 状态：可用

## 目标

完成一篇文章的创建、目录登记和后续更新。

## 创建文章

1. 在 [模板目录](../../templates/README.md) 选择模板，复制正文。
2. 打开 [知识库总目录](../README.md)，进入合适的分类。
3. 在 GitHub 的仓库文件页面新建文件，粘贴模板内容。文件名使用简短英文小写单词，以连字符连接，并以 `.md` 结尾。
4. 填写标题、日期、标签和正文，删除所有未使用的占位内容。
5. 用 Markdown 预览检查标题、列表和链接，再提交更改。

建议命名：`docs/notes/topic-name.md`。这是文件名示意，并非已有文章。

## 登记目录

编辑新文章所在目录的 `README.md`，在“文章索引”中加入相对链接和一句话说明。第一篇文章加入后，删除“暂未收录”的提示。

同一目录的链接可以写成 `[文章标题](topic-name.md)`。

## 更新已有文章

先核对原文，再修改结论或操作步骤。补充来源，更新文章的“更新日期”；内容过时但仍需保留时，将状态改为“待更新”，并说明原因。

## 完成检查

- 从分类页能打开文章。
- 文章的内部链接能打开对应文件。
- 正文没有模板占位文字。
- 事实和引用有可追溯的来源。
