# 个人上下文与偏好

- 更新日期：2026-10-11
- 发布范围：公开
- 用途：在不同 AI 工具之间接续个人背景、目标和协作偏好。

## 阅读入口

1. [个人偏好总结](preferences.md)：先了解沟通方式、学习方式和当前任务约定。
2. [记忆与个人上下文摘要](memory-summary.md)：了解已核实的背景、项目和关注主题。
3. [来源与覆盖范围](sources-and-scope.md)：核对依据、时间及未覆盖的信息。

这是一份静态摘要，后续需要更新；换用其他 AI 工具时，可以把这些文件作为背景资料提供给它。

内容依据本人可读取的聊天文字整理，**不是账号全部“已保存的记忆”的导出**。本人的新说明优先于旧摘要；某次提问不等于长期偏好或已完成的行动。
