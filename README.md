## 开始使用

1. 阅读 [快速上手](docs/guides/getting-started.md)。
2. 从 [文章模板](templates/README.md) 复制合适的模板。
3. 在对应分类中创建 Markdown 文件，写明结论和来源。
4. 将新文章链接加入该分类的 README。

[总目录](docs/README.md) · [维护约定](CONTRIBUTING.md)

## 查找内容

先按分类浏览；也可以在仓库中使用 GitHub 搜索，输入关键词查找文件内容。搜索是否能命中文档取决于 GitHub 的索引状态。

此仓库当前为公开仓库，提交的文档可被他人查看。只收录适合公开的内容。
