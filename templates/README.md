# 文章模板

选择模板，复制正文到对应分类的新文件中。模板中的“待填写”仅用于提示写作，正式文章提交前应替换或删除。

| 模板 | 用途 | 保存目录 |
| --- | --- | --- |
| [知识笔记](note.md) | 解释概念、记录学习结论 | `docs/notes/` |
| [操作指南](guide.md) | 记录操作和排错步骤 | `docs/guides/` |
| [项目复盘](review.md) | 总结项目结果和改进 | `docs/reviews/` |
| [资源收藏](resource.md) | 保存资料及推荐理由 | `docs/resources/` |
